⚙️ AI 模型设置（联网 / 本地）

工作台本身不能上网，AI 能力由你自配的大模型 API 提供。Key 仅保存在你本机 data/ai_config.json，不会上传。默认 通义千问（DashScope），申请地址 dashscope.aliyun.com。

联网模型 需要模型先上网获取信息，再进行分析。 工作台自身不能上网，因此调用带联网搜索能力的大模型。适用：个股资料补全、投资亮点/雷点、产品与客户、公司综合介绍、供应链与成本、股东户数、大盘概览、行业指数、研报检索、公告检索、异动归因、网络热议等。
本地模型 只需要模型分析本地数据、做逻辑推导。 例如分析本地财务数据库中的财报文本、已上传年报、复杂图表、生成分析报告等。当前财报解读会自动注入本地营收/净利全序列与同比·边际，不联网、不消耗检索额度。未配置本地模型时，自动回退到联网模型（但仍关闭联网检索）。

火山与百度为周期性重置免费额度（约 500 次/月、3000 次/月），按本工作台当前用量可长期免费；阿里 2000 次为一次性总额度、用完不再重置；内置搜索无免费额度，留作回退。
