- NOTE: 无。

### ITEM 2 · H1 的方向表述
- VERDICT: **不成立**
- EVIDENCE: `analyze_factor_corr.js:153-156` 定义 `drawdown_20d = (close − 20日最高) / 20日最高`，最高值取 `[i−20, i]` 含当日 → 该值 **≤ 0**，价格创 20 日新高时恰为 0；趋势上涨 → 指标数值**趋近 0（变大）**、回撤**幅度收窄**。§3 实证 `mom_20d·drawdown_20d = +0.602`、`ma_bias·drawdown_20d = +0.737`，均为正相关，同样指向「上涨 → 数值变大 / 回撤收窄」。§4 H1 却写「drawdown_20d 通常同步走阔（**回撤随上涨放大**）」，方向与因子定义及本报告自身的实证符号**相反**。
- NOTE: 这是可复算的方向错误，不是措辞瑕疵。若原意是「指标数值走高」，则「回撤走阔 / 放大」属口径混淆，须明确区分「指标数值」与「回撤幅度」。修正前 H1 不能原样保留为待验证假设。
